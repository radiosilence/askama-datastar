- **`Csp` and `SecurityHeaders`.** Every server wrote the same security middleware and the same policy by hand. `Csp::new()` is the policy STANDARD §8 gives, with `datastar()` for Datastar's `'unsafe-eval'`, `import_map(text)` for an import map's hash, `deny(directive)` for `script-src 'none'` and the like, and `allow(directive, source)` for extra sources such as `blob:`. `SecurityHeaders` is a layer setting it with `nosniff`, `X-Frame-Options: DENY` and `Referrer-Policy: no-referrer`, and leaves a header a route set itself alone.
